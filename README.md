This repository contains analyses done by Sunay Usluer, for the research article: 

  "Uncovering RNA Dependencies in Lung Cancer through CRISPR–Cas13d Functional Genomics"
  
It has four main folders:

1. sym_101_libraray_design= It comprises the code to modulate gene dependency, copy number, and expression data for the cell lines selected for the analysis. Then the code selects protein genes with various expressions, dependency and copy number levels to select 640 genes to test Cas13d activity.
2. Tracer_x_analyses= Tracer_X is a large lung cancer study, which comprises tumor and normal tissue RNA expression analyses from multiple donors. This folder consists of the code to conduct differential gene expression analysis between LUAD and LUSC samples vs. normal tissue samples, followed by plotting this data for follow up genes.
3. Figure_1_activity_tests= The folder consists of various pre-screen activity tests in selected cell lines and code to analyse and plot these data (Mainly presented in Figure 1 and Supplementary Figure 1).
4. Figue_5_Cell_cycle= This folder comprises the data plotting of cell cycle assays upon SNHG15, SNHG16 and MYC depletion.
